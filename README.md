### What I learned

While working on this project, I learned how to use `box-shadow` for the first time and how to create the shadow effect with CSS.

I also learned more about using semantic HTML elements. In particular, I understood why the `<article>` element can be a suitable semantic element for an independent blog-style piece of content.
